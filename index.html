📲 Install di iPhone

1. Buka aplikasi ini menggunakan Safari.

2. Tekan tombol Bagikan (Share) di Safari.

3. Pilih Tambahkan ke Layar Utama (Add to Home Screen).

4. Aktifkan pilihan Open as Web App jika tersedia.

5. Tekan Tambah (Add).
